A research agent for materials science.

MatAgent retrieves and reads the literature, identifies missing data, and formulates hypotheses screened by chemical-validity checks. Every run is recorded for review.

02

Reads the literature

MatAgent searches paper indexes, ranks the results, and answers questions from the page text, with page citations.

Finds and ranks papers

Each request becomes up to five search queries. The results are merged and ranked, and the top papers are downloaded.

Method LR 1.1 · Semantic Scholar, Google Scholar (with the scholarly package), arXiv fallback · lexical rank: title, abstract, recency, citations

Answers cite the page

Ask a question of a paper: the best-matching passages are retrieved, and a language model answers from them, citing pages as [p. N].

Method MMR 4.1⁠–⁠4.3 · BM25 over ~1,200‑character page‑text chunks · opt‑in: ColSmol‑500M page‑image ranking, read by a vision‑language model

One searchable knowledge base

Papers with their figures, mode runs, datasets, chat answers and Deep Research reports share one index. A vision-language model writes figure descriptions, labelled model-generated.

Method SQLite FTS5 BM25 + sqlite‑vec vector search (OpenAI embeddings), merged by reciprocal rank fusion · BM25 only without embeddings

Deep Research, plan first

A language model drafts a plan of sub-questions and the sources for each. You can edit the plan; the research starts only when you press Start.

Method quick / standard / deep: ≤ 3 / 6 / 10 sub‑questions, 0.4 / 1.2 / 3 M tokens · stopped early: partial report from findings, if any

03

Finds what is missing

MatAgent lists gaps in the data, asks a language model whether retrieved papers close them, and compares the values that sources report for the same property.

Gaps found by rules

Gaps are collected without a language model: from database coverage, a checklist of the domain's gap categories, and the database query. A few of their terms join the paper search.

Method GAR 2.1 · a checklist category stays open unless ≥ 2 reviewed records match it · record‑count gaps listed separately

Closure judged against papers

In one call, a language model decides whether any retrieved paper closes each gap. It must name the paper and quote it; the quote is not checked against the abstract.

Method ≤ 10 papers: title + first 600 characters of abstract · temperature 0 · GCS = 100 × closed ÷ judged · fallback: word overlap

Shows where sources disagree

Values with units are pulled from each source's summary by pattern matching and compared in pairs for the same property. Where values conflict, a language model re‑extracts them.

Method LCA 5.1 · |a − b| ÷ max(|a|, |b|): ≤ 1 % consensus, ≤ 10 % partial (adjustable), else contradiction · differing units not compared

04

Formulates hypotheses

Language-model prompts propose candidates. Rule-based checks screen them, then a language model reviews the rest against retrieved evidence and compares them in pairs.

Up to four generators

Each generator is a language-model prompt: inspiration, assumption hop and analogy, plus contradiction resolution when an LCA result is supplied.

Method quick: inspiration · standard: + assumption hop, analogy · deep: + contradiction resolution (needs an LCA result)

Rule-based checks before review

Before any language-model judgement, gates reject candidates that fail a hard check, including chemical rules for their material class. Soft checks only lower the rank.

Method hard: RDKit sanitisation · IZA code · Si/Al ≥ 1 (Löwenstein's rule) · composition ≤ 101 % · soft: charge balance, ionic‑radius mismatch

Reviewed against the evidence

A language model weighs each candidate against up to eight retrieved passages; “supports” and “disproved” stand only with a verbatim quote. A critic model rates flaws.

Method quoted “disproved” rejects · flaws fatal / major / minor → score 1⁠–⁠5 · a fatal flaw rejects, unless all would go

Compared head-to-head

A language-model judge compares candidates in pairs, blind to IDs, generator and lineage. A pair is won only if won in both presentation orders; a split is a tie.

Method Bradley⁠–⁠Terry fit, bootstrap intervals · order: gate, critic score, flaws, soft checks, then strength

Bounded effort

Each run has an effort tier that caps language-model calls and run time.

Method quick / standard / deep: ≤ 24 / 150 / 400 calls, 300 / 1,200 / 3,600 s · retrieval time not counted

Benchmarked on recent papers

44 cases from 2026 papers across 10 domains test whether the top hypotheses recover each paper's key points. A model drafted the key points; human spot-check is pending.

Method recall@3 by a language‑model matcher · branch vs base: paired‑bootstrap 95 % CI of Δrecall@3, lower bound > −0.05 · run by hand
